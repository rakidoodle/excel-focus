# Curriculum map

Canonical index of shipped lesson IDs, prerequisites, delivery mode and project connections. Generated from the runtime content with `node scripts/curriculum.cjs`; edit source records, then regenerate. “Available” means authored and accessible, not independently certified mastery. Advanced Excel follow-alongs are not browser simulations.

24 modern learning tracks are followed by the preserved original course. Professional Projects forms the applied capstone area with 32 case studies. The 250 lessons include 20 legacy entries retained for saved progress. Some legacy topics overlap modern explanations intentionally; IDs remain stable.
